# CP-014 — Browser Timezone Localization

## Tanggal
29 Oktober 2026 — 23:05 WITA

## Masalah
Server-side timestamps (Asia/Jakarta) ditampilkan apa adanya di browser, terlepas dari timezone user. User dari UTC+8, UTC+9, dll. akan melihat waktu Jakarta, bukan waktu lokal mereka.

## Solusi
1. **Server/DB**: Tetap Asia/Jakarta (CP-013)
2. **Browser**: Gunakan JavaScript `toLocaleString()` untuk konversi ke timezone browser user
   - Output `<span data-uts="{unix_timestamp}">` di Blade views
   - Script di layout: konversi semua `[data-uts]` elements ke browser local time
   - Fallback: server-rendered Jakarta time tetap ditampilkan sebelum JS jalan

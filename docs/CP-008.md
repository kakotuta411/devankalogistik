## 🔄 Model Relationships

### User
- `branch()` → belongsTo(Branch::class)
- `isSuperAdmin()` → role === 'Admin'
- `canWrite()` → role not in ['Executive_Viewer']

### Branch
- `shipments()` → hasMany(Shipment::class, 'origin_branch_id')
- `regions()` → belongsToMany(Region::class, 'branch_region')
- Global scope: BranchScope on branch_id

### Region
- `parent()` → belongsTo(Region::class, 'parent_code', 'code')
- `children()` → hasMany(Region::class, 'parent_code', 'code')

### Shipment
- `originBranch()` → belongsTo(Branch::class, 'origin_branch_id')
- `destinationBranch()` → belongsTo(Branch::class, 'destination_branch_id')
- `package()` → belongsTo(Package::class)
- `trackingEvents()` → hasMany(TrackingEvent::class)
- `manifests()` → belongsToMany(Manifest::class, 'manifest_items')
- `manifestItems()` → hasMany(ManifestItem::class)
- `invoices()` → belongsToMany(Invoice::class, 'invoice_items')
- `podImages()` → morphMany (POD uploads)
- Global scope: BranchScope on origin_branch_id

### Package
- `shipments()` → hasMany(Shipment::class)

### Manifest
- `originBranch()` → belongsTo(Branch::class, 'origin_branch_id')
- `destinationBranch()` → belongsTo(Branch::class, 'destination_branch_id')
- `items()` → hasMany(ManifestItem::class)
- `shipments()` → belongsToMany(Shipment::class, 'manifest_items')
- Global scope: BranchScope on origin_branch_id

### ManifestItem
- `manifest()` → belongsTo(Manifest::class)
- `shipment()` → belongsTo(Shipment::class)

### TrackingEvent
- `shipment()` → belongsTo(Shipment::class)
- `actor()` → belongsTo(User::class)

### AuditLog
- `actor()` → belongsTo(User::class)

### Invoice
- `branch()` → belongsTo(Branch::class)
- `items()` → hasMany(InvoiceItem::class)
- `shipments()` → belongsToMany(Shipment::class, 'invoice_items')->using(InvoiceItem::class)
- Global scope: BranchScope on branch_id

### InvoiceItem
- `invoice()` → belongsTo(Invoice::class)
- `shipment()` → belongsTo(Shipment::class)

## 📏 Business Rules
- **Resi format:** `TRK-{YYYYMMDD}-{SEQ:5}` (e.g., TRK-20261028-00001)
- **Manifest format:** `MNF-{YYYYMMDD}-{SEQ:5}`
- **Invoice format:** `INV-{YYYYMM}-{SEQ:5}`
- **Seal format:** `SEAL-{manifest_no}`
- **RBAC:** Admin (full), Head_of_Branch (branch-scoped), Leader_Supervisor, Executive_Viewer (read-only), Staf (write)
- **BranchScope:** Applied to Shipment (origin_branch_id), Manifest (origin_branch_id), Invoice (branch_id)
- **Print settings:** `storage/app/public/print_settings.json` (company_name, logo, header_text, footer_text, paper_format)


## ✅ Fixes (Post-Checkpoint — 2026-10-28)

### Bug: Login page showing dashboard layout
- **Cause:** `auth/login.blade.php` used `@extends('layouts.app')` — form login ditampilkan inside sidebar+navbar
- **Fix:** Rewrite sebagai standalone HTML (Sign-in template), no layout extension
- **Verify:** 200 OK, 0 references to sidebar/navbar/dashboard keywords

### Bug: Raw Blade source code leaking in index views
- **Cause:** Index views written via Python `f'''string'''` — `{ {{ var }} }` interpreted as f-string escaped braces, converting Blade `{{ $var }}` → `{ $var }` (single braces, not evaluated by Blade)
- **Fix:** Rewrite all 5 index views (shipments, manifests, invoices, users, branches) using plain string concatenation (no f-string)
- **Verify:** curl `/shipments` shows "10 shipment(s)" rendered properly, not `{{ $shipments->total() }}`

### Bug: GET /logout → 405 MethodNotAllowedHttpException
- **Cause:** Sidebar "Sign out" tombol memakai `<a href="/logout">` (GET), tapi route hanya menerima POST
- **Fix:** Ganti `<a>` ke `<form method="POST" action="/logout">@csrf<button type="submit">`
- **Verify:** curl POST `/logout` → 302 redirect to /login

### Bug: Sort header links showing as raw HTML text
- **Cause:** `{{ sortLink(...) }}` uses Blade `{{ }}` (escaped output), so function's `<a>` HTML was printed as text
- **Fix:** Changed to `{!! sortLink(...) !!}` (raw output) so HTML tags render properly
- **Verify:** curl shows `<a href="?sort=resi_no&dir=asc">Resi</a>` — proper clickable links

### Bug: Manifest show — "Call to a member function format() on string"
- **Cause:** `dispatch_time` and `receive_time` columns not cast to datetime in Manifest model → returned as strings, `->format()` fails
- **Fix:** Added `$casts = ['dispatch_time' => 'datetime', 'receive_time' => 'datetime']` to Manifest model (restored `$branchColumn`)
- **Verify:** curl `/manifests/{id}` → 200 OK

### Feature: Invoice create — cascading region selects
- **Change:** Added provinsi → kab/kota → kecamatan → kelurahan selects + JS cascading (same pattern as shipment create) above address textarea
- **Verify:** 9 references to customer_province/regency/district/village in view; page 200 OK

### Fixed layout: navbar & sidebar fixed, dynamic height, sign-out pinned
- **Change:** Rewrote layout with:
  - Navbar: `fixed-top` (34px tall)
  - Sidebar desktop: `position: fixed; top: 34px; bottom: 0` with flex column layout
  - Sidebar mobile: offcanvas (auto-hide on small screens)
  - Main content: `max-height: calc(100vh - 34px); overflow-y: auto` — scrolls independently
  - Sign-out: pinned at bottom of sidebar via `flex-shrink: 0`
  - Dynamic navbar height detection via JavaScript (measures actual navbar height, sets padding-top, max-height, sidebar top)
  - CSS fallback: `padding-top: 4.5rem; max-height: calc(100vh - 4.5rem)` to prevent FOUC
- **Verify:** All pages: main_top=34px (right below navbar), no overlap; sign-out at bottom; content scrolls within max-height
- **Note:** Mobile view uses offcanvas (auto-hide sidebar) which works correctly
- **Change:** Downloaded Bootstrap 5.3.3 CSS/JS + Bootstrap Icons to `public/css/`, `public/js/`, `public/fonts/`
- **Views updated:** `layouts/app.blade.php`, `auth/login.blade.php` — all `cdn.jsdelivr.net` URLs replaced with `{{ asset(...) }}`
- **Fonts:** bootstrap-icons.woff/woff2 copied to `public/css/fonts/` for relative path resolution
- **Verify:** All assets return 200; no CDN references remain; all pages 200 OK
- **Scope:** All 16 views + layout (excluding welcome.blade.php)
- **Change:** Converted all Tailwind utility classes to Bootstrap 5.3.3 equivalents:
  - `fg-white` → `text-white`
  - `bg-1` → `bg-dark`

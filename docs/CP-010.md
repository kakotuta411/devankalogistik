## Ringkasan Perubahan

### 1. Manifest Create — Semua Cabang Tujuan
- `ManifestController::create()` — dropdown cabang tujuan sekarang menampilkan **semua** cabang (termasuk cabang asal), untuk mengakomodasi pengiriman dikota yang sama
- Shipment checkboxes dikelompokkan per destination branch
- JavaScript filter: pilih cabang tujuan → hanya shipment ke cabang tersebut yang tampil
- Server-side validation di `store()`: reject jika shipment tujuan ≠ manifest tujuan

### 2. Complete Button (Manifest)
- Tambah method `complete()` di ManifestController
- Route `POST /manifests/{id}/complete`
- Tombol "Selesaikan" hanya muncul ketika status manifest = "Out for Delivery"

### 3. Shipment Status Sync
- `dispatch()`: Shipment Created → **In Transit**
- `receive()`: Shipment In Transit → **Arrived at Destination**
- `complete()`: Shipment Arrived at Destination → **Delivered**

### 4. Out for Delivery (Manifest + Shipment)
- Tambah method `outForDelivery()` di ManifestController
- Route `POST /manifests/{id}/out-for-delivery`
- Flow status baru:
  - Manifest: Draft → Dispatched → Received → **Out for Delivery** → Completed
  - Shipment: Created → In Transit → Arrived at Destination → **Out for Delivery** → Delivered
- `outForDelivery()`: Shipment Arrived at Destination → **Out for Delivery**
- `complete()`: Shipment Out for Delivery → **Delivered**

### 5. UI Updates
- Manifest show view: tombol "Out for Delivery" (status Received), "Selesaikan" (status Out for Delivery)
- Badge status warna: Out for Delivery = primary (biru)
- Shipment show view: tambah section "Manifest Terkait" — tabel manifest yang terhubung
- Shipment index: kolom koli hapus "kg"
- Manifest index: badge warna diupdate untuk "Out for Delivery" dan "Received"

### 6. Invoice Status
- Tambah method `markCancelled()` di InvoiceController
- Route `POST /invoices/{id}/mark-cancelled`
- Tombol "Batalkan" muncul untuk invoice status Draft
- Badge warna: Cancelled = danger (merah)

## Status Flow

### Manifest
Draft → Dispatched → Received → Out for Delivery → Completed

### Shipment
Created → In Transit → Arrived at Destination → Out for Delivery → Delivered

### Invoice
Draft → Paid / Cancelled

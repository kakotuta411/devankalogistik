# CP-013 — Timezone Fix: UTC → Asia/Jakarta

## Tanggal
29 Oktober 2026 — 22:50 WITA

## Masalah
`created_at` dan kolom datetime lainnya selalu tampil UTC. DB timezone config kosong → default UTC, sehingga timestamps disimpan di UTC tanpa konversi yang benar.

## Root Cause
- `config/database.php` → pgsql connection tidak ada key `timezone`
- `config('database.connections.pgsql.timezone')` → empty string (default UTC)
- PostgreSQL session timezone → UTC
- Laravel menyimpan timestamps di UTC, tapi karena DB timezone UTC, tidak ada konversi ke Asia/Jakarta

## Fix
1. Tambah `'timezone' => env('DB_TIMEZONE', 'Asia/Jakarta')` di `config/database.php` (pgsql)
2. Tambah `DB_TIMEZONE=Asia/Jakarta` di `.env`
3. Clear config cache

## Verifikasi
- ✅ DB timezone: Asia/Jakarta
- ✅ PostgreSQL session timezone: Asia/Jakarta
- ✅ Record baru: created_at = 29/10/2026 22:49:19 (Jakarta) = now() Jakarta
- ✅ Test record dibersihkan
